# Robotika Teknokrat Web Hub 🤖🚀

Official digital portal and legacy archive for the **Robotika Teknokrat** team at **Universitas Teknokrat Indonesia**. This platform serves as a high-performance organizational hub, showcasing technical excellence, competitive achievements, and tactical robotic units.

## 🌟 Overview
This website is designed to be a "Single Source of Truth" for the organization. It transitions from a simple landing page into a data-driven tactical dashboard, providing deep insights into our divisions, historical wins, and leadership structure.

## 🚀 Key Features
- **Tactical Division Hub**: Deep-dive pages for every robotic unit (Air, Land, Water), including sub-divisions like VTOL, ASV, and KRI.
- **Achievement Legacy Archive**: A comprehensive, visually-documented record of trophies and awards from 2023–2024, complete with "proof" imagery and impact statistics.
- **Interactive Organization Chart**: A dynamic visualization of the core executive board (BPH), divisional heads (Sekbid), and departmental hierarchies.
- **Cinematic Experience**: Integrated **Lenis Smooth Scroll** for high-end inertial navigation and **Framer Motion** for tactical micro-animations.
- **Modern Tech Stack**: Built with React 19, Vite, Tailwind CSS 4, and Lucide Icons.

## 🛠️ Design Philosophy
- **Modern Engineering Aesthetic**: Utilizing a Navy/Blue/Yellow palette with glassmorphism effects to evoke a high-tech laboratory feel.
- **Consistency First**: A project-wide design system with standardized 20px border-radii, strict grid alignments, and unified typography.
- **Performance Optimized**: Lightweight implementation using CDNs for heavy libraries to ensure fast load times and a fluid user experience.

## 📁 Project Structure
- `/src/pages`: Core application views (Home, Division, Achievements, Organization).
- `/src/data`: Centralized data store for robot specs, team members, and award records.
- `/src/components`: Atomic design components (UI/Sections) for modularity and reuse.
- `/src/index.css`: Custom design tokens and Tailwind 4 theme configurations.

## 🎓 About the Organization
**Robotika Teknokrat** is a premier robotics team in Lampung, Indonesia, dedicated to research, development, and competition excellence. We compete in prestigious national events such as KRI, KRTI, and KKI, consistently pushing the boundaries of autonomous systems and engineering synergy.
